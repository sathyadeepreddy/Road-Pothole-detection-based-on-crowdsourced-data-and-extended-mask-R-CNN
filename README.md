# PotholeAI – Road Pothole Detection System

**Created by: Punnam Sathyadeepreddy**

🌐 **Live Website:** https://huggingface.co/spaces/sathyadeepreddy/potholeai-sathyadeepreddy

An AI-powered road pothole detection system that uses computer vision to identify potholes from uploaded road images and videos.

### Features
- AI-based pothole detection
- Image and video analysis
- Bounding-box visualization
- Detection confidence scores
- Browser-based interface

### Technology
- YOLOv8
- ONNX Runtime Web
- HTML, CSS and JavaScript
- Hugging Face Spaces
